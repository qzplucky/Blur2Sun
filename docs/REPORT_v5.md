### 2.1.1 配对生成机制（核实记录）

**目录实际结构**（实测，非推断）：`paired_*` 目录并非 12s 全节奏流（那将是 ~7000 帧/天），而是数据准备阶段已抽好的子集——**每 ~2 min 保留一个 anchor 帧 + 其 +11s 的邻居帧**，目录即 anchor/neighbor 交替：

- 094 耀斑日：1242 帧 = 621 个 anchor-neighbor 组（覆盖 00:00–23:32），组间距 131s（部分 251s 缺帧）
- 094 宁静日：1296 帧 = 648 组

**配对代码**（`data_utils.py`）：`get_sorted_fits_files` 按 **DATE-OBS（header）**排序（注意：文件名字典序会把 6 位邻居排在 4 位 anchor 之前，不可用）→ `generate_non_overlapping_pairs` 连续非重叠配对 (0,1),(2,3)…，并以 **12±2s 间隔过滤兜底**（不满足则顺延跳过该帧；094 每天仅 ~24 帧顺延，即缺失邻居的 anchor）。

**三方口径对账**（正文 L93 / 表注 / 配对数的矛盾至此统一）：
- "Successive pairs are ~2 min apart" ✓ —— **相邻配对的起始时刻**相隔 131s（2.2 min）；
- "Raw pairs are formed from consecutive frames" ✓ —— 指时间排序后目录内的**连续两帧**（即 anchor+邻居，间隔 11s）；
- 每波段 1002–1093 对 ✓ —— 500–550 对/天，与"每 ~2.2 min 一对"完全一致。

**建议的统一措辞**（替换正文 L93 与表注）：
> The paired training set was constructed by retaining, every ~2 min, an anchor frame together with a neighboring frame 11 s later from the 12 s-cadence AIA stream; training pairs are formed from these consecutive frame pairs (in-pair interval 11±2 s), yielding ~500–550 pairs per band per day.

（子采样动机为设计推断，非实测：避免 ~7000 个高度冗余的连续对、把配对铺开覆盖全天强度 regime、控制 NCC 筛选规模。）

### 2.2 训练数据筛选：共享真值验证（两遍稳健阈值法）

**动机（为什么筛）**：Blur2Blur 训练假设"配对两帧共享同一无模糊真值 x，仅 PSF 退化与噪声不同"。若两帧间场景真实演化（耀斑脉冲相、快速环变化），该假设破裂，训练目标自相矛盾。必须在入训前剔除演化对。

**筛选公式**（`src/data_loader.py` L56-89，两遍法）：

第一遍——信号区 NCC（逐对计算）：

```
NCC_signal(i,j) = corr( a, b )，在 mask 上：
    mask = { p : img_i(p) ≥ P70(img_i) } ∪ { p : img_j(p) ≥ P70(img_j) }
    （P70 = 该帧 70 分位；若 mask 像素 <1000 则退回全图）
```

选信号区而非全图的原因：全图 NCC 被低计数噪声区（94/131/335 的暗区）系统性压低，对低信噪波段不公平；定标偏移/曝光差也被信号区 NCC 免疫（相关系数性质）。

第二遍——按（波段×日）分组自校准阈值：

```
分组：flare / quiet 两个数据根（不同处理链噪声底不同，混合会拉低阈值）
  med = median(NCC_signal)，MAD = 1.4826 × median|NCC − med|
  thr = med − 4 × MAD
  保留 ⟺ NCC_signal ≥ thr
```

中位−4×MAD 是稳健统计量：只剔低尾（演化对/伪影对），不受少数极端值影响；阈值随波段噪声水平自适应（094 的 thr≈0.88，211 的 thr≈0.9992——相差两个数量级但各自公平）。

### 2.4 推理输入构造与背景台扣除（v5 新增规范）

```
标准曝光帧（论文默认口径）:
  输入:  y = clip(obs_DN/s × EXPTIME, 0, ∞)          # 原生强度，不加底台
  输出:  x̂ = clip( model(y) − pedestal, 0, ∞ )
短曝光计数耗尽帧（仅耀斑槽位）:
  输入:  y = 原生 DN + offset;  offset = 手调逐通道常数 2/2/85/4/85/4/4 DN（非训练集中位）
  输出:  x̂ = clip( model(y) − offset − pedestal, 0, ∞ )
  pedestal = median( x̂[ring] ),  ring = 宁静圆环（输出台扣除，两口径一致）
```

floor 的作用：短曝光帧日面电平（0–2 DN）远低于训练分布（094 p50=2、171 p50=50–85 DN），MAP 先验在近零输入上工作异常；均匀底台经 PSF 卷积不变，可精确减回。 pedestal 扣除解决 floor 的副作用（模型重生成背景，见 §4.3）。

## 3. 网络架构与 v5 改动（完整版）

### 3.1 基线：MAP 深展开

10 个 MAPBlock 串行，每块 = 数据步 + 先验步；先验 PriorNet 为 4 层 32 通道 CNN（3×3 卷积 + GroupNorm + LeakyReLU），输出先验梯度场。PSF 算子：修正 PSF 2048（图像 2 倍），zero-pad FFT 线性卷积，左上裁剪。四代版本**只改数据步**：

| 版本 | 数据步 | 等效步长 | PSF | X93 094 脊残余 |
|---|---|---|---|---|
| v2 | `x ← x − α·Pᵀ(Px−y) − β·∇R` | α 自由学 | 8192 裁 1024（错） | 病态（负过冲黑斑） |
| v3 | 同 v2 | α 学到 **0.21** | 官方 rebin 2048 | **15.1%** |
| v4 | `x ← x·[Pᵀ(y/(Px+ε))/Pᵀ1]^γ − β·∇R` | 乘性 | 同 v3 | 9.5% |
| **v5** | **`x ← clamp(x − k·(P(x)−y), 0) − β·∇R`** | **k init 1.0** | 同 v3 | **6.2% → 扣台 3.2%** |

### 3.2 v3 缺陷根因（三条实测证据）

**① 收敛速率不足（主因）**。加性梯度下降对 `‖Px−y‖²` 的每频率误差衰减率：

```
v3:  err_k(f) = (1 − α·|P̂(f)|²)^k ,  α ≈ 0.21
BID/v5: err_k(f) = (1 − |P̂(f)|²)^k ,  k = 1.0
```

十字衍射脊线对应 |P̂|≈0.3–0.7 的频段：α=0.21 时 10 步只修正该频段误差的 15–40%；k=1 时同样 10 步修正 >90%。

**② 训练损失对去芒零激励，且主动锁死小步长**。训练目标 `L1(P(x̂₁),y₂)+L1(P(x̂₂),y₁)`：十字像素占全图 0.02%，对 L1 梯度贡献≈0；同时调大 α 会放大安静日面噪声、恶化全局 L1——两股力共同把 α 压到 0.21（实测学到的值）。

**③ 排除性对照**（均实测）：
- 非"训练数据无 X/M"：训练集 094 最亮 120 帧 120/120 含强十字（突出度 2.97 DN，核 16461 DN）；v3 在训练日亮帧同样残留（宽臂指标 0.874）；
- 非迭代不足：v3 结构 +10 迭代无变化（0.744→0.725）；
- 非亮度失配：输入 ×8/×40 不去芒；×0.03 时输出发散（PriorNet 的 GroupNorm 破坏尺度等变性，低 DN 端先验接管——次因，v5 已缓解）。

### 3.3 v4（乘性 EM）的失败分析（为什么不是"理论上更快"）

- **收敛饱和于 6–7%**：纯 EM 10/30/50 步 = 19.2/6.7/5.9%——EM 的比值更新在低频段校正同样受限，追不上 BID；
- **通量不守恒 → 背景伪影**：比值更新在 PSF 散射亏损区持续抬升背景，M2.6 171 输出全盘泛白（实测宁静区被抬 +30 DN/s 量级）；
- 数值上需 ε+截断兜底（暗区 0/0）。

### 3.4 v5 的改动依据：官方 BID 源码实证

读 `deconvolve_image.py`（Hofmeister et al. 2024, Solar Phys. 299:77）更新循环：

```python
img_decon_con = irfft2(rfft2(img_decon) * psf_fft)    # (1) P(x)
deviations    = img_decon_con - img                    # (2) P(x) − y（图像域）
img_decon    -= k * deviations                         # (3) x ← x − k(Px−y), k=1
if constrain_positive: img_decon[img_decon < 0] = 0    # (4) 每步正性截断
```

**结论：BID 是 Landweber 迭代（k=1）+ 每步正性截断 + 2× 零填充 + 大 PSF，而非乘性 EM**（"Basic Iterative Deconvolution"之名易误导）。v5 完整复刻该数据步并保留可学习性与先验：

```
x_lw   = clamp( x − k·(P(x) − y), min = 0 )     # k = exp(log_k)，初始化 log_k=0 → k=1.0（=BID）
x_next = x_lw − β·PriorNet(x_lw)                # β = exp(log_beta)，初始化 0.01
```

改动清单（相对 v3/v4，仅 `src/model2_map.py` MAPBlock）：
1. 数据步从 `Pᵀ(Px−y)` 伴随形式改为图像域偏差 `P(x)−y`（少一次 Pᵀ 平滑，推理快 ~15%）；
2. 步长初始化 0.21→**1.0**（BID 同款），保留可学习（训练后 k=0.61–0.77，见 §4.2）；
3. **每步正性截断**（v3 仅在网络末端 softplus）——抑制 Landweber 在强源周围的负过冲振铃（v2 黑斑伪影的同类机制）；
4. 先验项不变（β·PriorNet 加性小步）。

### 3.5 纯算法对照实验（无训练、同输入、同算子）

|---|---|---|---|---|

### 4.3 "波段色雾"根因与输出台扣除（论文须写）

**现象**：v3/v4/v5 耀斑输出全日面有一层波段色雾（094 绿、171 黄），BID 背景纯黑。
**根因**：输入加训练分布 floor 后，模型无法区分人造底台与真实背景，按训练统计把背景**重新生成到训练中位水平**；减 floor 残留正台：094 +0.22 DN（=1.07 DN/s），171 +4.9 DN（=2.45 DN/s）——即色雾。BID 黑背景因其输入为近零过剩帧且 `estimate_background` 扣除平滑背景估计。
**修复**：§2.4 的 pedestal 扣除（宁静圆环中位数）。效果：宁静背景精确归零；脊残余全面下降（094 6.2→3.2%，M2.6 171 8.9→0.0%）。论文表述建议：*"a smooth background pedestal, estimated from a quiet annulus, is subtracted from the deconvolved image (cf. the background estimation in BID)"*。

## 5. v5 vs BID 总结论与已知局限

| 维度 | v5 | BID |
|---|---|---|
| 十字衍射去除 | ≈BID（094 3.2% vs 1.4%；171/M26 场景持平或更优） | 好 |

| 对输入 DN 电平 | 敏感度低（floor+扣台规范） | 对低电平失稳（0.08s 域白斑，2026-10-17 实测） |

2. M2.6 094 / X9.3 171 脊区 ~31–37% 残余为真实发射结构，BID 同样残留——非方法缺陷；
3. 垂直亮线为探测器饱和溢出（bleed），非 PSF 成分，任何去卷积无法去除；
4. 5 epoch 为快验数字；50 epoch 完整训练（进行中）后更新。

#### 7.2.2 DEM 敏感性专项诊断（回应对"曲线重合"的质疑）

**质疑**：Hofmeister et al. (2025)（PSF 论文）报告修订 PSF 去卷积使耀斑 DEM

2. **DEM 敏感性被两件事稀释**（都不是 bug）：
   a. **15% 系统误差项**：+14% 的图像变化被 15% 误差棒吞掉；
   b. **top-15% 大核掩膜平均**（3841 px）。

3. **宁静区 ROI 不满足 PSF 论文前提**：原 darkest-box 变异系数 1.18，
   是全日面最均匀 160 盒（0.29）的 4.1 倍——不是"大而均匀宁静区"。

   （宁静日冕 EM 仅为耀斑 1/50，正则化冷 bin 行为主导；PSF 论文的"不变"
   指曲线形状，此处形状差 <10%@峰）。
4. **B2S 保守是设计后果**：核区 +14% vs BID +28-37%。成对一致性损失 +
   学习先验天然保守（与噪声表低计数通道的保守性一致），不是缺陷。
5. **正则化强度非主因（极限测试）**：reg_tweak 1.0→0.003（300 倍范围），

## 10. 比较框架纠正：差分 → 前向残差（2026-10-22，用户指出）

### 概念错误（已纠正）

此前的"差分面板"（x̂−y）把**模糊观测 y 当真值**——错误。y=P·x+n，
x̂−y 混入真实去散射光（物理、平滑、本该为负）与方法伪影，不是误差图；
据此做的"两区校正"强行令去卷积结果匹配模糊图，物理错误（抹除真实去散射光）。

### 正确框架

**前向残差 P·x̂ − y**（观测域自洽性）——去卷积结果重新模糊后与观测比较，
即 Blur2Blur 训练目标与 DEM χ² 的同口径指标。已重写
`test_proposed_v5_flare.py`：残差在**方法原始输出**上计算（显示层两区
校正仅用于面板，不进残差——其径向过渡被 P 模糊后会成假环）。
两法用同一把模型内 PSF 算子。整数底区域掩膜 + σ=1.5px 显示轻平滑保留。

### 结果（必须写入论文的诚实发现）

| 波段 | B2S 残差 | BID 残差 | 比值 |
|---|---|---|---|
| 094 | ±10% | ±0.6% | ~15x |
| 131 | ±20% | ±1.5% | ~10x |
| 171 | ±25%（日缘环） | ±20-60%（日缘环更大） | 相当 |
| 193 | ±40% | ±1.5% | ~25x |
| 211 | ±50%（内部红=整流偏置 +44%） | ±0.6% | ~80x |
| 335 | ±10% | ±0.4% | ~25x |

**BID（10it）的前向自洽性比 B2S 好 10-80 倍**（171 相当，两者日缘都过预测）。

### 解读（不可回避，也不可误读）

1. BID 的小残差 = 半收敛早期的安全解：数据拟合完美但**去卷积不彻底**
   （Hi-C FWHM 26.3 vs obs 26.0——BID 几乎没锐化；B2S 24.3 唯一超过 GT）
2. 单纯追求前向残差会reward"什么都不做"——该指标必须与去卷积进度
   （FWHM/结构）指标配对呈现
3. B2S 的残差分解：**(a) 整流偏置伪影**（211 内部 +44%，与独立测量一致，
   v5.1 修复中）；**(b) 先验正则化的主动偏离**（193/171 的结构残差）——
   MAP 框架下正则化本就以数据不一致换取稳定性，其价值须由其他指标
   （DEM χ² 1.54 vs 1.76、Inv-SSIM、Hi-C）佐证
4. 论文表格将同时报告前向残差与去卷积进度两类指标，不选择性呈现

- 所有网格图（DEM 7x4 B2S/BID、slot1202、验收 7 波段）的比较面板改为
  前向残差口径；plot_dem_grid.py 同步
